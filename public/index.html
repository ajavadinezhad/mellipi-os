Native workspace transitions and an indicator that moves with you. Keep different tasks in different spaces without losing your place.

What’s new in Mellipi

The 0.1.20 preview completed an offline install, Secure Boot, and graphical sign-in in a blank VM. See Install for the published downloads.

Find and install apps

Mellipi Software searches APT and can use Flatpak and Snap when configured. On a fresh offline install, refresh the APT index before searching for system packages.

Files and Terminal

Browse files and run commands in built-in apps that share the desktop’s theme and accent.

Make the taskbar fit

Place it on any edge, float it, or size it to its contents. Compact and Extra compact reduce its footprint.

High contrast in your theme

Make text and keyboard focus easier to see while keeping the theme’s colors. Each theme remembers its own contrast setting.

Capture to PNG or clipboard

Capture a window, a region, or the full screen. Save the PNG, copy it to the clipboard, or do both.

Recover a working version

Save the installed desktop version and restore it from a signed APT archive. The VM test verified that a document, desktop settings, and an installed app survived the update and rollback.

Add Mellipi with APT

noble / amd64

Repository details are being configured. The installation guide will contain the verified address and signing key.

For a fresh minimal base, download the setup helper, inspect it, then add the signed repository and install the desktop. The signing key is scoped to Mellipi.

Archive signing-key fingerprint

Already running Mellipi? After adding the source, use sudo apt install --only-upgrade mellipi-shell to update the core without adding the full desktop profile. Future updates arrive through your normal package manager.
