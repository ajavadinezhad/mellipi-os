# Mellipi desktop captures

These images show the actual Mellipi interface rendered by its native
compositor in an isolated Wayland session with a fresh private profile.
They are not mockups or captures of a personal desktop.

- `desktop-settings.webp`: Appearance settings, Forest theme, floating left taskbar.
- `desktop-launcher.webp`: Centered Apps & windows launcher in the same theme.

Both captures are 1440 × 900. Firefox and Files are selected as demo favorites.
Installed application availability can vary between systems. The original PNG
captures were converted directly to WebP; no UI elements were composited.
