Mellipi introduces its new branding and keeps an upgrade path for existing installations.

### New features
- New `mellipi-shell` and `mellipi-desktop` packages give fresh installations the Mellipi name.
- Transition packages carry existing desktop settings forward during upgrades.

### Improvements
- Renamed the desktop, login and lock screens, installer, website, and package source.
- Kept the original repository, stars, and earlier download URLs.

### What we tested
- BIOS and UEFI live boot, full UEFI installation, login, lock and unlock, and upgrade with apps open passed.
- A fresh BIOS disk installation was not repeated.

### Known limits
- Disable Secure Boot before starting this image.
