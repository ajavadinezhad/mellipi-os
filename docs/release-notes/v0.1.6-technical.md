# Mellipi 0.1.6: original technical notes

Mellipi 0.1.6 is a native Wayland desktop for Ubuntu 24.04 (noble), amd64, systemd/logind.

Use the signed package repository for installation and future updates:
https://ajavadinezhad.github.io/abstract-os/#install

- `abstract-shell`: core desktop; does not change your display manager or force a logout.
- `abstract-desktop`: optional complete desktop profile for a supported minimal Linux base.

This release includes initial input discovery, keyboard-layout validation and virtual-terminal resume fixes. Clean minimal installation, password login, lock/unlock, audio, upgrade/recovery and installed Settings workflows were checked in isolated environments. Other distributions and architectures are not yet certified.

Verify downloaded packages against `SHA256SUMS`. Matching bundled-component sources and notices:
https://ajavadinezhad.github.io/abstract-os/sources/0.1.6/manifest.json

Native compositor changes activate at the next normal logout and login. Save work before logging out.
