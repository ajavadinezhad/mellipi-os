**Preview** for Ubuntu 24.04 amd64. Try it from the live image; a full install to disk has not been verified.

### New features
- Browse the web and edit text with Mellipi Browser and Mellipi Editor, alongside Files and Terminal.
- See what uses disk space with Storage Analyzer and check running processes in System Monitor.
- Record audio with Sound Recorder, use the built-in clock tools, and mark up PDFs.

**Built-in tools.** The preview bundles web browsing and text editing beside Files and Terminal, and brings disk usage, process monitoring, recording, clock tools, and PDF markup into the desktop suite.

### Improvements
- One default app per job in the ISO, with competing desktop apps removed.
- The file chooser, icons, and controls share a consistent style across built-in apps and themes.
- The installer and sign-in screen follow the desktop theme.

**A shared desktop style.** Built-in apps use the same file chooser and visual controls, while the sign-in and installer screens follow the same theme. The image ships one default app for each role.

### Bug fixes
- Skip unnecessary logout steps when no app windows are open.

### What we tested
- BIOS and UEFI live boot passed, and the UEFI guest reported Secure Boot enabled.
- The installer opened in UEFI and Mellipi Browser launched in BIOS.

**What the VM checks cover.** The shipped ISO passed its checksum check and booted as a live desktop under both BIOS and UEFI. Secure Boot was confirmed inside the UEFI guest. Opening the installer verifies that it starts; it does not establish that installation completes.

### Known limits
- A full installation to disk is still unverified. The signed APT update channel is unchanged.
