# Mellipi 0.1.8: original technical notes

Abstract is now **Mellipi**. This is the original project repository; its existing star and previous releases are preserved.

- Renamed desktop, Settings, login greeter, lock screen, installer, website and package-manager source.
- New `mellipi-shell` and `mellipi-desktop` packages, with small transition packages for existing Abstract installations. Existing settings and runtime compatibility paths are preserved.
- Minimal Ubuntu 24.04 base with Mellipi as its only desktop, plus a terminal and essential applications.
- Signed package and ISO checksums, corresponding sources, and a detailed verification report accompany this release.

Verified: BIOS and UEFI USB boot; complete UEFI installation, disk-only boot, password login, lock/unlock, normal graphical package-manager authentication, and upgrade continuity with apps open. A fresh BIOS installation was not repeated for 0.1.8. Secure Boot remains unsupported.

Existing published archives retain their original bytes and names. Old download and APT URLs remain available through the compatibility repository.
