# Mellipi 0.1.20: original technical notes

Mellipi 0.1.20 targets Ubuntu 24.04 amd64. The live image includes a minimal Ubuntu base, the Mellipi desktop, Files, Terminal, and Mellipi Software.

- Find apps from APT and from Flatpak or Snap when configured. After an offline install, use **Refresh system packages** in Software.
- Place the taskbar on any edge, make it float, or fit it to its contents. Choose Compact or Extra compact density.
- Enable high contrast per theme and capture the screen, a window, or a region to PNG or clipboard.
- Restore a saved desktop package version from the signed APT archive with `mellipi-recover`.

The installer uses the Ubuntu-signed EFI boot chain. The release was tested in a UEFI Secure Boot VM. Physical hardware compatibility varies.

See the [USB and installation guide](https://github.com/ajavadinezhad/mellipi-os/blob/main/docs/live-iso.md) and the [signed APT setup](https://ajavadinezhad.github.io/mellipi-os/#install). Verify the download using the included SHA256 file or signed checksum manifest.
