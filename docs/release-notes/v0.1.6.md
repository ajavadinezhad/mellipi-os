This is the package release for Ubuntu 24.04 amd64 with systemd and logind. It can add the Mellipi desktop to a supported minimal Linux installation.

### New features
- Choose the core desktop or the complete desktop profile.
- The core package leaves your display manager in place and does not sign you out.

**Installation profiles.** The core profile adds the native Wayland session without changing the display manager. The complete profile is intended for a minimal Linux installation.

### Bug fixes
- Find input devices during desktop startup.
- Validate keyboard layouts before applying them.
- Restore the session when returning from a virtual terminal.

### What we tested
- Minimal installation, password login, lock and unlock, audio, upgrade, and recovery passed in isolated tests.

**Session and system controls.** Isolated checks covered the installed Settings workflows, audio, password sign-in, lock and unlock, and package upgrade and recovery. These checks apply to Ubuntu 24.04 amd64.

### Upgrade notes
- Sign out and back in once to activate native compositor changes.
