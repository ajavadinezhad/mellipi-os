First live USB and graphical installer for Ubuntu 24.04 amd64.

### New features
- Try Mellipi from a USB drive or install it with the graphical installer.
- The image includes one desktop, Foot terminal, Files, an editor, a browser, and a package manager.

**A complete live desktop.** The image starts from a minimal Ubuntu base and includes the tools needed to try the desktop without installing a second desktop environment. The installed system removes live-only installer components and ships without a developer account or SSH server.

### Bug fixes
- Give newly opened native apps keyboard focus.
- Show a fallback cursor when the intended cursor is unavailable.
- Restore the graphical authentication prompt for package updates.
- Correct the installer’s disk partition planning.

### What we tested
- BIOS and UEFI live boot and full virtual disk installation passed.
- Password login, lock and unlock, and package authorization passed after installation.

**First boot after installation.** The exact image was installed to private BIOS and UEFI disks and booted with the USB disconnected. The checks covered keyboard input, rejection of an incorrect lock password, successful unlock, and package search and authentication from the Updates button.

### Known limits
- Disable Secure Boot before starting this image. VM tests do not cover every physical graphics, Wi-Fi, or audio device.
