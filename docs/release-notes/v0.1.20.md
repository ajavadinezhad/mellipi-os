Live and install image for Ubuntu 24.04 amd64.

### New features
- Search APT in Mellipi Software, plus Flatpak and Snap when configured.
- Refresh system packages from Software after an offline installation.
- Move the taskbar to any screen edge, float it, or fit it to its contents.
- Choose Compact or Extra compact taskbar spacing.
- Save a screenshot of the screen, a window, or a region as PNG, or copy it to the clipboard.
- Save and restore a desktop package version from the signed APT archive.

### Improvements
- Each theme remembers its own high contrast setting.

### What we tested
- Offline UEFI installation, Secure Boot, and graphical sign-in passed in a private VM using the Ubuntu signed EFI boot chain. Physical hardware compatibility can vary.
