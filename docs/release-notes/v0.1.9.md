Administration and recovery tools for Ubuntu 24.04 amd64.

### New features
- Manage user accounts, passwords, time zones, and automatic time from Settings.
- Back up chosen files and desktop settings, verify the backup, and restore files into a separate folder.
- Save working desktop package versions and restore them from the password protected Recovery session, even if desktop startup fails.
- Enter a password using the lock screen’s on-screen US keyboard.
- Boot through the signed Ubuntu EFI chain on compatible machines.
- Maintainers can check update repository health and inspect read-only hardware diagnostics.

**System administration.** Account removal preserves personal files and protects the last unlocked administrator. Time settings include automatic time, installed time zones, and manual UTC entry.

**Backups and recovery.** Personal files restore into a new folder, while desktop settings can be restored at the next sign-in. The Recovery session skips the compositor and user startup scripts so a broken login script does not block repair.

### Bug fixes
- Clear stale graphics and input state when resuming from sleep; see the remaining display limitation below.

### Upgrade notes
- Sign out and back in once to activate native session changes. Existing settings are kept.

### What we tested
- BIOS live boot and a full Secure Boot UEFI installation passed; a fresh BIOS disk install was not repeated.
- Password login, lock and unlock, graphical package authorization, and recovery passed in private QA.

**Exact image and installed packages.** The fresh UEFI disk install booted with Secure Boot and kernel lockdown. Package checks also exercised pointer-only unlock, virtual terminal return, display power cycling while locked, and restoring a session after deliberately broken startup scripts.

### Known limits
- Virtio S3 resumed the kernel but left the display inactive; visual resume remains unverified.
- The lock field has no AT-SPI password object, and backups are unencrypted.

**What recovery covers.** Backups are for selected files and desktop settings. Package rollback requires the exact version to remain available in a trusted repository.
