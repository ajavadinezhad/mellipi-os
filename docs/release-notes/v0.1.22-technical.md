# Mellipi 0.1.22 Preview: original technical notes

Mellipi 0.1.22 is a preview of the standalone Ubuntu Noble image. It ships one default app for each job, including Mellipi Browser, Editor, Files, and Terminal, plus the updated theme, file chooser, and installer styling.

The ISO checksum matched. The live desktop booted in BIOS and UEFI VMs. In UEFI, the guest confirmed Secure Boot was enabled and opened the installer. In BIOS, Mellipi Browser opened. A full install to disk has not been validated for this image.

Use the ISO and its matching SHA-256 file below. The standalone packages are also included. The existing signed APT channel is unchanged.

Bundled, unchanged upstream runtime and Calamares sources are available in the [corresponding source archive](https://ajavadinezhad.github.io/mellipi-os/sources/0.1.20/manifest.json). The matching Mellipi project source and Qt 6 layer-shell build input are attached below.
