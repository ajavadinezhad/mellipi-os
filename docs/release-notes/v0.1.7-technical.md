# Mellipi 0.1.7: original technical notes

A bootable live USB and graphical installer built from a fresh **Ubuntu 24.04 amd64 minimal base**, with **Mellipi as the only desktop**. Includes Foot terminal, Files, an editor, browser and package manager.

The released ISO passed private KVM acceptance for:

- BIOS and UEFI USB boot, plus terminal input.
- Full BIOS and UEFI installation to private virtual disks, followed by disk-only boot and password login.
- Desktop locking: wrong password rejected, correct password unlocks.
- Automatic authorization-agent startup, Updates-button authentication, usable package search and the original Synaptic app-menu entry.
- Removal of live-only installer components, with no developer account, SSH server or extra desktop session.

This release fixes native app startup focus, cursor fallback, graphical package-manager authentication and Calamares partition planning. Tests used the exact image below, without live patches or manually started authorization agents.

**Secure Boot must be disabled.** Virtual-machine tests do not certify every physical GPU, wireless or audio device. The installation guide covers trying the image before installing.
