# Deep workflow and recovery audit

Baseline: Mellipi `0.1.22+local.24` on the test PC, with current workspace source. The review used disposable fixtures, local archive validation and source inspection. It did not change the live desktop or publish packages.

## Reproduced so far

| Priority | Workflow | Evidence and acceptance |
| --- | --- | --- |
| **Critical** | Screen locks while logout is waiting for an app | Using the real shell bridge and exit controller with a fake Editor that stayed open after its close request, a locked snapshot redacted all windows and emitted `readyToExit` once. The shell must never treat that privacy-redacted list as proof that apps are closed. Test the race with an unsaved document and mock all session commands. [Shell bridge](../../desktop/src/native_app.py), [Session exit](../../desktop/src/session_exit.py) |
| High | Calendar: edit the same personal event in two windows | Starting from one event, window A changed its title and stale window B changed its room. The final record silently lost A's title. The store reloads inside its lock but only checks whether the record still exists. Require the original revision on save/delete; show a conflict with a way to keep the draft. [Calendar](../../desktop/src/mellipi_calendar.py) |
| High | Editor: reload while preserving edits, then crash | Private Qt test showed an original recovery file on disk. Reload moved the unsaved text to a modified new tab, deleted the old recovery file, and no replacement was written even after an explicit draft flush. Commit or queue a replacement draft before clearing the original; test reopening from the draft. [Editor](../../desktop/src/mellipi_editor.py) |
| High | Files: Open from a subfolder search picks the wrong item | With one selection in the normal list and a different selected nested result, Enter opened the nested file. File Actions → Open opened the hidden list selection instead. Both routes should resolve the same visible selection. [Files](../../desktop/src/mellipi_files.py) |
| High | Photos: creating the chosen output concurrently | A private Save As fixture created the destination after the chooser returned. The original bytes were silently replaced. Use no-overwrite publication for new files and revalidate identity after intentional replacement confirmation. [Photos](../../desktop/src/mellipi_photos.py) |
| High | PDF: pathname replaced while a marked-up document is open | Real Poppler displayed pages from the replacement, while the old markup remained dirty. Export then refused the changed source and offered no recovery. Tie render/search/export to one source revision and preserve pending markup when the revision changes. [PDF Viewer](../../desktop/src/mellipi_pdf.py) |
| High | Clocks: an alarm fires while the queue is locked | A private real `fire` process exited with “Calendar alarms are busy.” Its alarm remained in the queue, but its systemd timer was one-shot and won't deliver again until a later restore. Retry promptly for bounded transient lock or notification errors, and prove the notification is delivered once. [Alarm queue](../../desktop/src/mellipi_alarm_queue.py) |
| High | Shell: rapid workspace switches across outputs | Holding the window worker and issuing two workspace picks on different outputs produced only the first compositor command. Use latest intent per output and verify both final selections. [Shell bridge](../../desktop/src/native_app.py) |
| High | Space Map: restore a maximized window | The arrange fixture reported a successful restore but issued only resize for a maximized checkpoint. Native resize clears maximized state. Restore the compositor state as well as the rectangle and verify it on both Wayland and XWayland. [Arrangements](../../desktop/src/arrangements.py) |
| High | Settings: a child opens but never becomes ready | A private unready live-child fixture produced two timeout notices and never tried a replacement. Restore a bounded retry path for the child owned by the failed request. [Settings host](../../desktop/src/settings_host.py) |
| Medium | Wi-Fi: failed join invalidates an in-flight scan | A mocked blocked scan followed by a wrong password left the old cached list. The scan result was discarded by revision guard and no follow-up was scheduled. Refresh the cache after failure and preserve the inline error. [System services](../../desktop/src/system_services.py) |
| Medium | Disks / Monitor: closing while a worker runs | In both private Qt fixtures, an injected 200 ms worker wait delayed an independent 20 ms GUI timer to around 205 ms. Disks can wait up to nine seconds; Monitor waits without a bound. Defer closure without blocking the UI. [Disks](../../desktop/src/mellipi_disks.py), [Monitor](../../desktop/src/mellipi_monitor.py) |
| Medium | Disks: Safe Remove partially succeeds | Private UDisks fixture unmounted the first volume and failed on the second busy one. Power-off was correctly avoided, but the UI kept showing the first volume as mounted because it never re-enumerated after the error. Always refresh after an attempt and report the partial outcome. [Disks](../../desktop/src/mellipi_disks.py), [UDisks backend](../../desktop/src/disk_backend.py) |
| Medium | Photos: copying a large preview silently reduces the image | Opening an 8000×4500 image in preview mode put a 2560×1440 image on the clipboard. Label the action Copy Preview and show copied dimensions, or provide a separate bounded full-resolution action. [Photos](../../desktop/src/mellipi_photos.py) |
| Medium | Experimental administrator prompt: exceptionally long description | On a private 800×600 Wayland display, a synthetic long administrator action produced a non-resizable **428×1314** dialog. The operation text needs a constrained, scrollable area so the password field and Cancel stay reachable. The stock agent remains the default. [Authorization](../../desktop/src/mellipi_permission_agent.py) |

The lock reviewer reproduced a lifecycle failure with a fake owned idle timer: changing an initially healthy child's exit status produced no status signal and no restart. That can disable idle locking and before-sleep locking until the policy is reapplied. Add bounded child recovery and surface permanent failure. The physical session was not locked or suspended for this test. See [idle_policy.py](../../desktop/src/idle_policy.py).

Existing scoped tests still passed for Browser (18), Terminal (1), Software (25), and the shell's interaction speed, Space Map, display configuration and lock keyboard checks (16 combined). Those passes don't cover the new failures; there was no new reproduced issue in Browser, Terminal or Software during this pass. Real media capture and package writes remain outside these fixtures.

The specialized app review also covered Recorder, Media and Calculator. Duplicate-media queue behavior needs a real playback fixture before treating it as a bug. Physical drives were never touched.

## Installation and publication

- All **52 release-tool tests passed**. This covers disposable signed APT metadata and tamper checks, installer target guards, Secure Boot artifact checks and update renewal; it does not boot or install the current candidate.
- The **checked-in** noble archive signature verified against its local keyring and the metadata expires February 10, 2027. Its newest Mellipi shell is **0.1.20**, and the checked-in site installer also points to **0.1.20**. The PC runs **0.1.22+local.24**. A clean installation from the checked-in image cannot be used as acceptance evidence for the locally installed fixes. Build and test a versioned package/ISO pair, then publish the same version throughout the signed archive and website once authorized.
- The site and desktop theme data match: regenerating the export yielded exactly the same **16 themes** as the website and publication copies. The exporter still imports PyQt5, although the desktop build targets Qt 6; clean Qt 6 developer and release environments need an extra toolkit solely to regenerate it. Port the exporter and compare all palettes before switching.
- Physical mixed-scale outputs, actual HDMI brightness and USB removal, headset capture, and suspended-session recovery are still separate acceptance gates. Use the [hardware test matrix](../hardware-validation.md), preserving the regular session and leaving destructive tests to an owned VM or a backed-up disk.

## Repair verification

- A privacy-redacted lock snapshot now cancels logout review and requires fresh consent after unlock. The regression checks the shell bridge and simulates an app with unsaved work and a pending close.
- Calendar rejects stale writes and deletes and lets users save an edited draft as a new event. Editor persists a replacement recovery draft before discarding the old one; Files resolves Open against the visible search selection. Alarm delivery retries transient contention and notification failures within a bounded window.
- Photos publishes new exports without overwriting a file created after Save As and identifies reduced-size preview copies. PDF renders, searches and exports from the same opened revision, preserving markup after replacement. Disks refreshes after partial removal, and Disks and Monitor defer close while their workers finish.
- Workspace requests retain the latest choice per output. Arrangement snapshots preserve maximized state and the normal restore rectangle. Settings can recover from an unready child it owns; failed Wi-Fi joins refresh the network list while preserving the error. Idle locking watches and restarts a failed timer with bounded retries.
- The private authorization fixture measured **420×328** on the same 800×600 display after the fix. Long operation text scrolls independently of the password and action buttons. The website theme exporter now runs on Qt 6 and all **16** exported palettes match the published copies byte for byte.
- The desktop suite passed **339** tests with one skip, and all **52** release-tool tests passed. On the packaged DRM binary, the private Space Map test passed eight checks, including restoring maximized Wayland and XWayland windows on hidden workspaces and recovering their original normal geometry. The private Settings window passed seven checks.
- The first live ISO boot reached the desktop with Secure Boot enabled and revealed a real-process idle regression: Linux ties the parent-death signal to the thread that started the child. Startup now keeps that thread alive to reap the timer. A real-process regression proves the timer survives startup, restarts after termination, and stops on shell close. The corrected local package is **0.1.24**.
- The corrected **0.1.24** ISO reached the live desktop in a two-core, 4 GB UEFI VM. The guest reported Secure Boot enabled and the expected version of all three packages. The resume listener restarted with a new PID after termination. A full install to a blank disk and a reboot into it remain separate gates; the public archive and download were not changed.
