# Mellipi edge-case audit — November 17, 2026

Audit following the 0.1.27 motion and edge fixes. Priorities reflect the reproduced effect. These are findings and proposed regression checks; this audit does not change the installed desktop.

| Priority | Reproduced case | Repair and regression check |
| --- | --- | --- |
| High | **Browser deletes a competing download destination.** A real Qt WebEngine download replaced a file created after the destination chooser accepted the path, and reported Saved. | Download to private staging and publish without clobbering new files. For an intentional replacement, confirm and recheck the original identity before publication. Assert both the destination bytes and download receipt. |
| High | **Files cuts the wrong file if its path is reused.** After Cut, another process replaces the item at the cut path. Paste moves the replacement and reports success. | Pin source identities for Mellipi-authored Cut data and reject changed entries at Paste. Keep external clipboard formats interoperable. |
| High | **Recorder recovers the wrong unfinished WAV.** Replacing a listed staging file while its recovery chooser is open causes Recorder to publish the replacement audio and remove the replacement staging file, then report success. The two fixture recordings had different PCM samples. | Pin the identity of each listed recovery item and verify it on the worker's file descriptor before copying or removing anything. |
| High | **Monitor's End Process can target a collapsed child.** In the process tree, select a child, then collapse its parent. End stays enabled and prompts for the now-hidden child. The fixture did not send a signal. | Clear selection when an ancestor collapses and verify visibility again immediately before requesting a signal. Keep PID and generation checks. |
| Medium | **Escape leaves taskbar focus captured.** In nested Wayland, the outer compositor focused the right window and Escape reached Mellipi. The shell requested keyboard interactivity to be disabled but did not commit its taskbar surface. A forced taskbar resize committed the pending change, but the keyboard left only on a subsequent input event. | Commit the taskbar surface on a keyboard-mode change and resync focus after the layer commit. Test one Escape while the pointer is stationary, then verify native keyboard routing to the previous app as well as visual focus. |
| Medium | **Rapid Mute and Wi-Fi clicks lose intent.** With delayed fake backends, two Mute clicks produce one toggle; Wi-Fi Off followed by On runs only Off. | Preserve Mute parity and the latest requested Wi-Fi state. Make the terminal state explicit after failures. |
| Medium | **Wi-Fi merge and escaping can hide the active network.** A stronger disconnected BSSID overwrote an active BSSID with the same SSID. An SSID ending in a literal backslash was dropped by the delimiter split. | Keep the active row while grouping duplicate SSIDs and parse escaped fields with an escape-aware scan. |
| Medium | **Battery selection is overwritten by an older result.** Selecting BAT1 during a delayed BAT0 read ends with BAT0 selected; both requests target BAT0. | Tag snapshots with the requested selection, ignore stale results, and refresh the latest requested battery. |
| Medium | **Media saves a different queue after an external open.** With a save chooser open for queue A, a concurrent MPRIS OpenUri switches to queue B. The saved playlist silently contains B. The fixture used actual WAV files and the OpenUri handler, with playback disabled. | Snapshot the queue on Save or detect and report its replacement before writing. |

The full desktop suite passed **379 tests, with one skip**. The separate system-focused run passed **74 tests**. The new reproductions above are gaps in existing coverage; they did not write to real user documents, send process signals, or modify the current networking, displays, packages, or session.
