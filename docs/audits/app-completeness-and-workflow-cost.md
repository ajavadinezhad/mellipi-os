# Native apps: critical gaps and workflow cost

This audit covers Mellipi's native app suite and the desktop shell. It is based on source and existing test coverage. A timeout or blocking call found in code identifies a mechanism, not a measured delay on a real PC. Prioritize workflows that can lose data, block a normal task, or hide whether an operation succeeded.

| App | Critical gap or workflow friction | First change and acceptance |
| --- | --- | --- |
| Files | Ctrl+F filters entries in the current folder. It cannot find a file nested in a project. Existing transfer progress, receipts and retry should be retained. | Add an opt-in, cancellable search within the current folder and its descendants. A nested file can be found and opened without changing folders. No background index. [Files](../../desktop/src/mellipi_files.py) |
| Terminal | Closing an idle tab asks for the same confirmation as closing one with a running job. | Safely recognize an idle shell; close it in one action. Preserve confirmation for active or unknown processes. [Terminal](../../desktop/src/mellipi_terminal.py) |
| Browser | Every website permission request is denied. Mic and camera workflows are impossible. Ordinary session restoration is also absent. | Add a clear origin-specific allow/deny prompt with a one-time grant before promoting it as a default browser. Next add opt-in tab restore that never restores private windows. [Browser](../../desktop/src/mellipi_browser.py) |
| Editor | External changes are detected on Save, but the user is offered only overwrite or cancel. Bounded open/mapped disk work and autosave can run on the GUI thread. | Offer Reload and a way to compare or preserve edits. Verify external changes, dirty buffers, large files and slower mounts before moving I/O off the UI thread. [Editor](../../desktop/src/mellipi_editor.py) |
| Calendar | Activating an imported event does nothing. Event search, personal recurrence, and reminders are missing. Month/day updates expand event recurrences on the UI thread. | Open a read-only event detail from the agenda, then add event search and reminder support. Measure month switching with a large recurring ICS fixture. [Calendar](../../desktop/src/mellipi_calendar.py) |
| Clocks | Alarm state is in memory; leaving Calendar can cancel alerts even though the user may expect an alarm to outlive the window. | Keep scheduled alarms in an event-driven session service, with saved enabled alarms and clear handling of sleep or missed alerts. Add one-click timer presets. [Clocks](../../desktop/src/mellipi_clocks.py) |
| Recorder | A WAV close or publish failure can remove the staging recording. Audio drain and writes also run on the GUI thread. | Preserve recoverable partial audio, report its location, and verify faults during write, finalize and publish. Then move disk writes to a bounded worker. [Recorder](../../desktop/src/mellipi_recorder.py) |
| Photos | The viewer refuses images above 16 megapixels and decodes synchronously during navigation. | Decode a screen-sized preview on a worker without lowering original export resolution. Test with a large photo folder and unsaved edits before navigation. [Photos](../../desktop/src/mellipi_photos.py) |
| PDF | Pages are raster images. Search locates a page but text cannot be selected or copied, and a page turn launches another renderer. | Add a selectable text layer and a bounded adjacent-page cache. Verify a searched phrase is highlighted and copyable. [PDF](../../desktop/src/mellipi_pdf.py) |
| Media | No audio/subtitle track picker; a failed queue item leaves no clear next action. | Add explicit track selection and Retry/Skip in queue failures. Verify multiple languages, off/on captions and a corrupt middle item. [Media](../../desktop/src/mellipi_media.py) |
| Disks | No safe whole-drive removal; device changes require manual refresh. | Use UDisks events to refresh while preserving selection and offer guarded Safe Remove for the drive, including all mounted volumes. Test with a disposable virtual drive. [Disks](../../desktop/src/mellipi_disks.py) |
| Software | Updates are installed one at a time and then rescanned. An older search can hold up a corrected query. | Show per-source update results as they arrive, group selected updates by package manager, and keep receipts. Make the latest search win without piling up subprocesses. [Software](../../desktop/src/mellipi_software.py) |
| System Monitor | End Process signals only SIGTERM. The entire process tree is rebuilt every two seconds. | Offer explicit Force Quit after a grace period and use the same PID identity protections. Update rows in place and verify sorting and selection with many processes. [Monitor](../../desktop/src/mellipi_monitor.py) |
| Calculator | No release blocker found. Percent syntax divides by 100, which differs from some calculator workflows. | Explain the existing result and consider explicit percentage and percentage-change actions. Preserve current expression semantics. [Calculator](../../desktop/src/calculator_core.py) |

## Desktop and cross-app waits

- **Software updates:** The backend queries package sources concurrently, but the Updates view waits for the whole batch. Search already consumes per-source results. Reuse that pattern so a slow or offline source cannot hide results from the others. Test with one immediate source, one delayed source and one failed source; show the fast result immediately and report incompleteness explicitly. See [software_sources.py](../../desktop/src/software_sources.py) and [mellipi_software.py](../../desktop/src/mellipi_software.py).
- **Settings startup:** The separate window is purposeful. Its cold-open path still retries on a 100 ms timer until the window appears, with a five-second cutoff. Use the existing ready and window-added events for handoff, leaving a bounded timeout only for errors. Measure cold and warm input-to-visible separately before changing startup policy. See [settings_host.py](../../desktop/src/settings_host.py).
- **Quick Settings Wi-Fi:** Entering Connections requests a scan. Connect uses the same single-worker queue as that scan. Show cached networks immediately and keep connecting free to proceed while a scan is stalled. Verify with a delayed scan fixture; keep audio controls independent. See [QuickPanel.qml](../../desktop/native/QuickPanel.qml) and [system_services.py](../../desktop/src/system_services.py).
- **Space Map restore:** Restore waits 40 ms per matched window and performs repeated snapshots; six windows have 240 ms of fixed delay before IPC. Cache topology and use native configure events where necessary, retaining any required legacy compatibility. Verify focus responsiveness and restore correctness with 1, 6 and 24 windows, mixed Wayland/XWayland, a closed window, and a removed output. See [arrangements.py](../../desktop/src/arrangements.py).
- **External monitor brightness:** Each accepted DDC value can trigger a detect, write and read-back. Group a drag into the final value while keeping monitor identity checks and providing immediate pending feedback. Measure on actual HDMI hardware. See [brightness.py](../../desktop/src/brightness.py).
- **Launcher and taskbar:** The launcher can stay open while a GIO launch is acknowledged, and a focus change can rebuild taskbar groups and rescan the catalog to match windows. Instrument key-to-results, click-to-acknowledgement and click-to-window separately. Preserve launch errors and verify whether grouping needs optimization with a larger window fixture. The current [benchmark](../../desktop/tools/benchmark.py) measures idle resource use, not these interactions. See [native_app.py](../../desktop/src/native_app.py).

Fix recording recovery first. Prioritize browser permissions before recommending the optional browser as a daily default. The best first workflow pass is Wi-Fi queueing, progressive Software results, then recursive Files search; these remove waiting or repeated steps from tasks users already try.

One stress result: in a private Qt offscreen run with 2,000 synthetic weekly events, Calendar's median month refresh took about 192 ms and selected-day refresh about 113 ms across five runs each. That measures synchronous recurrence expansion and UI construction in this fixture; it does not represent normal calendars or end-to-end desktop latency. Use the same fixture when testing a recurrence cache.

## Follow-up implementation

- Recorder streams to a bounded worker, preserves staging on write or publish failures, and recovers PCM files with interrupted headers. Files has an explicit Subfolders search. Software progressively shows update results, accepts multi-selection, and bounds concurrent replacement searches.
- Browser offers one-time camera and microphone permission for the active HTTPS origin, plus explicit saved-tab restore. Terminal distinguishes confirmed idle shells. Editor can preserve edits when reloading external changes and writes drafts off the UI thread. Calendar has event search, details, repeat options and reminders; user timers keep alarms independent of the Calendar window.
- Photos supports large images as read-only previews; full-resolution editing/export for those images remains outside this pass. PDF selection is in a separate page-text view with adjacent-page caching. Media, Disks, Monitor and Calculator received the controls listed above.
- Wi-Fi scans no longer block joins. Settings uses readiness events, external brightness commits once per slider drag, and native Space Map restore skips the fixed legacy sleep. Launcher hands off promptly while reporting errors; taskbar matching reuses bounded results.

The first uncached month in the large Calendar fixture and explicit Editor open/save still perform synchronous work. Physical HDMI control, camera/microphone permission through actual sites, USB removal, and real alarm delivery were not exercised in this pass.
