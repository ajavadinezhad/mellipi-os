A quieter kind of desktop

Small details.
A better everyday.

A compact spine keeps your desktop grounded. Open a window, move between spaces, find a setting—and get back to what you were doing.

01 / SPACE

Movement with purpose.

Native workspace transitions and an indicator that moves with you. Keep different tasks in different spaces without losing your place.

02 / FOCUS

One place to find things.

Search apps and open windows together. Keep your favorites close and give the rest of your screen back to your work.

03 / CHARACTER

A desktop that feels whole.

Coordinated themes, wallpaper, accents and lock-screen styling. Choose a compact layout and place the spine on any edge.

04 / RESTRAINT

Polish with a light footprint.

Built for a two-core, 4 GB target. Static theme assets and package-manager updates keep unnecessary background work out of the picture.

Make some space

Start with Linux.
Add Abstract.

Abstract is a desktop environment, not a separate Linux distribution. The current binary packages target Ubuntu 24.04 amd64 with systemd and logind.

Early-access software. Try a virtual machine or a test PC first, and keep a recovery login available. Other distributions and architectures are not yet certified.

Package-manager installation

noble / amd64

Repository details are being configured. The installation guide will contain the verified address and signing key.

For a fresh minimal base, download the setup helper, inspect it, then add the signed repository and install the desktop. The signing key is scoped to Abstract.

Archive signing-key fingerprint

Already running Abstract? After adding the source, use sudo apt install --only-upgrade abstract-shell to update the core without adding the full desktop profile. Future updates arrive through your normal package manager.
