# Abstract moved to Mellipi

The desktop is now **Mellipi**. Active development, releases and installation instructions are at [Mellipi OS](https://github.com/ajavadinezhad/mellipi-os) and the [Mellipi website](https://ajavadinezhad.github.io/mellipi-os/).

This repository preserves published Abstract releases and its original signed update endpoint. Version 0.1.8 transition packages migrate existing installations to Mellipi while preserving user settings.
